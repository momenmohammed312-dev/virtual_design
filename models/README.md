# Models Directory

Place your Qwen3-VL Vision model files here to enable **AI Autopilot**.

### Required Files:
1. **Model File**: `Qwen3-VL-7B-Instruct-Q4_K_M.gguf` (or any Qwen-VL compatible GGUF)
2. **Vision Projector**: `mmproj-model-f16.gguf`

The system will automatically detect these files on the next run.
If missing, the system will use the **Rule-Based Smart Analyzer** as a fallback.
